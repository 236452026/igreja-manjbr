# Site da Igreja MANJBR

Projeto Integrador Web Standard (ENIAC). Site institucional com Home, Nossa História, Contribua e Ministérios (integrado ao MySQL).

> README completo será finalizado ao fim do projeto.

## Estrutura
- `frontend/` site (Vite)
- `backend/` API (Node + Express)
- `database/` scripts SQL
- `docs/` documentação e pendências
